# Tasks

One file per task: `TASK-NNN-short-title.md`. An implementation thread receives only its task file plus
[PROJECT_GOAL.md](../PROJECT_GOAL.md), [PROJECT_INSTRUCTIONS.md](../PROJECT_INSTRUCTIONS.md) and
[PROJECT_STATUS.md](../PROJECT_STATUS.md), so a task must be understandable with that alone: name the files and
functions to read, not the whole repository.

Task state lives in PROJECT_STATUS.md, not in the task file.

## Template

```markdown
# TASK-NNN — Title

## Objective

## Scope

## Non-goals

## Relevant components/files

## Acceptance criteria

## Required tests

## Dependencies
```
